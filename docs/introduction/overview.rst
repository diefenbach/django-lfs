What is LFS?
============

LFS (Lightning Fast Shop) is an open source online shop built on Python and
Django. It covers the whole way from the catalog to the paid order and comes
with its own management interface for the daily work in a shop. Prices, taxes,
shipping and payment follow configurable rules instead of code changes in the
core.

Features
========

The features are listed on the website: https://django-lfs.com/#features.
